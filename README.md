Полный, обновленный и готовый к запуску дистрибутив **FlipCTL** (интерфейса Flipper One на базе движка Slint) с расширенной поддержкой оборудования, реальных приложений, динамического управления пакетами и поддержкой микрокомпьютеров **Raspberry Pi Zero W**.

---

## 🌟 Ключевые улучшения и новые возможности

1. **Динамический менеджер пакетов (`pacman` / `apt` / `dnf`)**:
   - Автоматическое определение окружения хоста (Arch Linux, Manjaro, Debian, Ubuntu, Raspbian, Fedora).
   - Прямая проверка исполняемых файлов в `PATH` перед опросом системы (исключает ложные запросы на установку уже имеющихся пакетов вроде `python3`).
   - Корректная трансляция имен зависимостей между дистрибутивами (например, `python3` -> `python`, `libsdl2-2.0-0` -> `sdl2`).

2. **Фирменная янтарная подсветка Flipper Amber (`#FF8200`)**:
   - Встроенный аппаратный преобразователь палитры: монохромная матрица переводится в точный теплый оттенок янтарного дисплея Flipper.
   - Управление через переменную: `FLIPCTL_AMBER=1` (янтарный) или `FLIPCTL_AMBER=0` (классический монохром).
   - Четкое пиксельное масштабирование: `FLIPCTL_SCALE=2` (или 1-8x).

3. **Turnkey-поддержка Raspberry Pi Zero W + Waveshare 1.44" LCD HAT (ST7735S 128x128)**:
   - Полная совместимость с [Waveshare 1.44inch LCD HAT](https://www.waveshare.com/wiki/1.44inch_LCD_HAT).
   - **Zero Compilation**: готовый драйвер и мост на чистом Python (`rpi-zero-w/waveshare_st7735.py`), не требующий многочасовой компиляции на слабом одноядерном ARMv6.
   - Поддержка всех 8 аппаратных кнопок и 5-позиционного джойстика (GPIO 21, 20, 16, 6, 19, 5, 26, 13).
   - Автоматический инсталлятор и готовый `systemd` сервис.

4. **Работающий Doom на x86_64 и ARM**:
   - Полноценный самодостаточный бандл `doom.fap.AppImage` с движком `dsda-doom`, набором уровней `freedoom1.wad` и откалиброванной палитрой Flipper Amber.
   - Запускается в 1 клик на ноутбуке/ПК без эмуляции архитектуры.

5. **Готовый пакет полезных приложений (`sample_apps/`)**:
   - 🔊 **Volume Control** (`volume.fap.py`): регулировка громкости PipeWire/PulseAudio и Mute.
   - ☀️ **Brightness** (`brightness.fap.py`): управление яркостью экрана ноутбука (KDE D-Bus / sysfs).
   - 🔋 **Battery Health** (`battery.fap.py`): телеметрия батареи (мощность Вт, вольтаж, здоровье %, циклы).
   - 📶 **Network Monitor** (`network.fap.py`): активный WiFi, уровень сигнала dBm/%, IP, шлюз, скорость KB/s.
   - 🎵 **Media Remote** (`media.fap.py`): управление медиаплеерами через MPRIS (Spotify, VLC, Chrome).
   - 🔒 **System Control** (`sysctl.fap.py`): блокировка экрана, спящий режим, отключение дисплея, аптайм.
   - 🌐 **Ping Latency** (`ping.fap.py`): пинг и проверка потери пакетов в реальном времени.
   - 📊 **Sysmon** (`sysmon-x86_64.fap.AppImage`): нативный Rust-мониторинг CPU, памяти, дисков и температуры.
   - 🎮 **Doom** (`doom.fap.AppImage`): классический шутер с адаптацией к экрану.

6. **Универсальный сетевой интерфейс и пульт**:
   - Веб-интерфейс доступен в локальной сети на порту `8899` (`http://<ip>:8899`).
   - Полноценное управление с телефона, планшета или другого компьютера.

## 🚀 Быстрый запуск на ПК / Ноутбуке

### 1. Клонирование репозитория
```bash
git clone https://github.com/ValentinStars/flipctl.git
cd flipctl
```

### 2. Установка демонстрационных приложений
```bash
bash sample_apps/install_apps.sh
```

### 3. Запуск
```bash
# Обычный запуск в окне с янтарной подсветкой:
./start.sh

# Запуск в фоновом/серверном режиме для локальной сети:
./start.sh lan
```

После запуска веб-интерфейс и пульт управления доступны по адресу:
`http://localhost:8899` (или `http://<ip-ноутбука>:8899` в локальной сети).

## 🍓 Запуск на Raspberry Pi Zero W (Waveshare 1.44" LCD HAT)

Дисплей **Waveshare 1.44inch LCD HAT** оснащен контроллером **ST7735S (128x128 SPI)** и 8 кнопками (3 кнопки + 5-позиционный джойстик).

### Установка в 1 команду:
```bash
cd rpi-zero-w
sudo bash install.sh
```

Инсталлятор:
- Установит библиотеки для работы с SPI и GPIO без компиляции кода.
- Активирует интерфейс SPI в ядре Linux.
- Настроит и запустит сервис `flipctl-st7735.service`.

Подробная документация и распиновка: см. [rpi-zero-w/README.md](rpi-zero-w/README.md).

## ⌨️ Управление клавишами

| Кнопка Flipper | Клавиатура ПК | Waveshare HAT | Действие |
|---|---|---|---|
| **OK** | `Return` / `Enter` | `Key 1` / Нажатие джойстика | Выбор / Запуск / Подтверждение |
| **Back** | `Escape` / `Backspace` | `Key 2` | Назад / Выход из приложения |
| **Menu / Switcher** | `Tab` / `m` | `Key 3` | Переключатель задач / Меню |
| **D-Pad Up** | Стрелка `Вверх` | Джойстик `Вверх` | Навигация вверх |
| **D-Pad Down** | Стрелка `Вниз` | Джойстик `Вниз` | Навигация вниз |
| **D-Pad Left** | Стрелка `Влево` | Джойстик `Влево` | Навигация влево / Назад |
| **D-Pad Right** | Стрелка `Вправо` | Джойстик `Вправо` | Навигация вправо / Подменю |
